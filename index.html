0. Навіщо потрібні форми і як вони працюють

Форма — це спосіб, за допомогою якого користувач передає дані сайту: логін і пароль, замовлення, відгук, пошуковий запит, реєстрація на подію. Сама HTML-сторінка лише відображає поля; обробляє дані сервер (скрипт на PHP, Python, Node.js тощо).

Шлях даних

  1. Користувач заповнює поля й натискає кнопку submit.
  2. Браузер перевіряє поля (наприклад, required, type="email").
  3. Браузер формує пари name=value для кожного поля, що має атрибут name, і надсилає їх на адресу з action методом з method.
  4. Сервер приймає дані, обробляє їх і повертає нову сторінку-відповідь.

Приклад пар, що надійшли на сервер: username=Ірина&city=dnipro&news=yes. Поле без name на сервер не потрапляє.

Основні елементи форми: контейнер <form>, поля введення (<input>, <textarea>, <select>), підписи <label> і кнопки.

1. Контейнер <form>

Усі поля огортаються парним тегом <form> … </form>. Він об’єднує поля в єдиний блок для відправлення даних на сервер.

<form action="#" method="post"> … </form>

action — URL обробника (під час верстки ставлять заглушку #). method — спосіб передачі: GET — через адресний рядок, POST — у тілі запиту (паролі, великі обсяги).

GET чи POST?

GETPOST
Де передаються даніВ адресному рядку: сторінка?name=value&…У тілі запиту, не видно в адресі
ОбсягОбмежений довжиною адресиПрактично необмежений
Закладка / посиланняМожна зберегти й поділитисяНе можна
Коли використовуватиПошук, фільтри — безпечні запитиПаролі, реєстрація, замовлення, файли

Якщо method не вказано, браузер використає GET. Інші корисні атрибути: target="_blank" (відповідь у новій вкладці), autocomplete="off" (вимкнути підказки браузера), novalidate (вимкнути перевірку браузера).

Важливо: форми не можна вкладати одна в одну, але на сторінці може бути кілька окремих форм.

2. Елемент <input>

Одинарний тег — «хамелеон» форм: вигляд і поведінка залежать від атрибута type.

typeПризначенняОсобливості
textОднорядкове полеІм’я, місто, логін
passwordПарольПриховує символи
emailЕ-поштаПеревіряє наявність @
numberЧислоЛише цифри; атрибути min, max
dateВибір датиВбудований календар
radioРадіокнопкаОдин варіант з групи (однаковий name)
checkboxПрапорецьКілька варіантів одночасно
submitВідправленняНадсилає дані на сервер
resetОчищенняСкидає введене

Корисні атрибути

name — системне ім’я поля (латиницею), за яким сервер розпізнає дані. placeholder — сіра підказка в порожньому полі. required — поле обов’язкове.

Радіокнопки й прапорці

Розмір:
<input type="radio" name="size" value="s"> S
<input type="radio" name="size" value="m" checked> M

<input type="checkbox" name="news" value="yes"> Отримувати новини

Радіокнопки об’єднуються в групу однаковим name — обрати можна лише одну. Прапорець, який не відмічено, на сервер не надсилається. Кнопки: type="submit" value="Надіслати" і type="reset" value="Очистити".

3. Підписи — <label>

Зв’язує підпис і поле: клік по тексту ставить курсор у поле (зручно для чекбоксів і радіокнопок на телефоні). Зв’язок — значення for дорівнює id поля.

<label for="user-name">Ваше ім’я:</label>
<input type="text" id="user-name" name="username" placeholder="Введіть ім’я">

Навіщо це потрібно: зручність (більша клікабельна область), доступність (екранні читалки озвучують підпис разом із полем), порядок у коді.

Другий спосіб — вкласти поле всередину label

<label><input type="checkbox" name="news" value="yes"> Отримувати новини</label>

Тоді for та id не потрібні. Підпис не слід плутати з placeholder: підказка зникає, щойно користувач почне вводити текст, тому вона не замінює label. Значення id має бути унікальним на сторінці, а name може повторюватися (як у радіокнопок).

4. Багаторядковий текст — <textarea>

Парний тег для відгуків і коментарів. Атрибути: rows (висота в рядках), cols (ширина в символах), placeholder.

<textarea id="comment" name="user_comment" rows="4" cols="35"></textarea>

Текст між відкриваючим і закриваючим тегами стає початковим значенням поля (у <textarea> немає атрибута value). Корисні атрибути: maxlength — обмеження довжини, required, readonly. Розмір rows і cols можна замінити стилями CSS. Пробіли й переноси рядків усередині тегу зберігаються, тому не ставте зайвих відступів між тегами.

5. Розкривні списки — <select> і <option>

Коли варіантів багато, використовують <select>; кожен пункт — тег <option>.

<select id="city" name="user_city">
  <option value="kyiv">Київ</option>
  <option value="dnipro">Дніпро</option>
</select>

Атрибути списку

АтрибутПризначення
value в optionЗначення, яке піде на сервер (текст між тегами бачить лише користувач)
selected в optionПункт обрано за замовчуванням
disabled в optionПункт показано, але обрати не можна (наприклад, «Оберіть місто»)
multiple в selectМожна обрати кілька пунктів (Ctrl/Shift)
size в selectСкільки пунктів видно одночасно (список замість розкривного меню)

Якщо value не вказано, на сервер піде текст пункту. Групувати пункти можна тегом <optgroup label="Назва групи">.

6. Спробуйте самі: робоча форма

Заповніть форму й натисніть «Надіслати» — під нею з’явиться те, що браузер надіслав би серверу (пари name=value). Зверніть увагу: поле «Ім’я» обов’язкове, а прапорець без позначки в результаті відсутній.

Підсумок і типові помилки

  • Усі поля — всередині <form> з action і method.
  • Без атрибута name дані поля не передаються.
  • Для radio в групі name однакове, id завжди унікальний.
  • label for має дорівнювати id поля.
  • Пункти списку — лише <option> всередині <select>.
  • Паролі передаємо методом POST і з type="password".
  • <input> — одинарний тег; <form>, <label>, <textarea>, <select> — парні.
